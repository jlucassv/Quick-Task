# Quick Task — Protótipo de Organização de Tarefas

## Sobre o projeto
Quick Task é uma proposta de interface para organizar tarefas pessoais e profissionais, acompanhar prazos, prioridades e status.

## Objetivo
Criar um protótipo de média fidelidade no Figma, aplicando conceitos de usabilidade, hierarquia visual e navegação intuitiva.

## Público-alvo
Pessoas que desejam organizar atividades diárias e acompanhar suas prioridades.

## Funcionalidades representadas
- Visão geral das tarefas do dia.
- Resumo de tarefas concluídas e pendentes.
- List View com tarefas, prazos, prioridades e status.
- Tela de detalhes da tarefa.
- Ações visuais para voltar à lista e marcar uma tarefa como concluída.

## Decisões de design
- Azul como cor principal, branco para cartões e cinza-claro no fundo.
- Tipografia sem serifa para facilitar a leitura.
- Menu lateral para acesso às áreas principais.
- Hierarquia visual clara com títulos, cartões e espaçamento.
- List View para facilitar a comparação das informações.

## Telas
1. Visão geral.
2. Minhas tarefas.
3. Detalhes da tarefa.

## Fluxo sugerido
Visão geral → Minhas tarefas → Detalhes da tarefa → Voltar à lista.
